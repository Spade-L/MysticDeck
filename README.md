# 灵术牌 (MysticDeck)

> 一款隐秘西幻风格的数字消除卡牌游戏。

《灵术牌》是一款基于 [Dora SSR](https://dora-ssr.com/) 引擎开发的策略休闲小游戏。玩家需要在有限回合内，通过算术消除卡牌，并利用丰富的特殊硬币构建策略，体验兼具休闲与烧脑的肉鸽（Roguelike）闯关之旅。

## 🎮 核心玩法

1. **数字运算**：玩家将带有数字的“硬币”拖拽到“卡牌”上。如果硬币的加减乘除运算结果等于卡牌的目标数字，点击确认即可消除该卡牌。
2. **回合制生存**：战斗以回合为单位推进。每回合结束时，场上未消除的卡牌会扣除玩家的血量，血量归零则游戏失败。
3. **胜利条件**：在限定回合内消除足够数量的卡牌即可通关。

## 🪙 硬币系统（9种特殊硬币）

游戏打破了纯计算的枯燥感，引入了 9 种功能各异的硬币，极大丰富了策略深度：

| 硬币类型 | 功能说明 |
| :--- | :--- |
| **普通硬币** | 数字可用于加减计算（上限999）。 |
| **乘法硬币** | 数字可用于乘法计算（上限999）。 |
| **冰冻硬币** | 放在卡牌上后，回合结束时倒计时不会减少。使用后本关内消失。 |
| **折扣硬币** | 放在卡牌上后，按照百分比降低目标数字（上限100%）。 |
| **回复硬币** | 成功消除卡牌时，玩家恢复1点血量。 |
| **干扰硬币** | 具有负面限制，回合结束后如果未使用会自动消失。 |
| **万能硬币** | 无视数字和任何附加条件，直接消除一张卡牌。 |
| **复制硬币** | 成功消除卡牌时，复制该卡牌的目标数字。 |
| **增长硬币** | 放置在场上后，每过一个回合自身数字翻倍。 |

## ⚙️ 游戏特色与系统

*   **局外养成**：通关后可通过“同类型硬币合成”提升硬币数值（折扣币上限100%），并消耗资源强化“血量上限”、“硬币删除次数”及解锁新硬币类型。
*   **BOSS 关卡**：BOSS 战存在特殊卡牌，除数字外还需满足额外条件才能消除，或消除后触发负面效果，考验玩家的应对策略。
*   **扫荡功能**：通关首个 BOSS 关卡后解锁扫荡功能。扫荡奖励与历史最高通关数挂钩，单次扫荡奖励有上限（1000 MAX）。

## 🛠️ 技术栈与开发环境

*   **游戏引擎**：[Dora SSR](https://dora-ssr.com/)（一款跨平台开源游戏引擎）
*   **开发语言**：TypeScript
*   **版本控制**：Git（托管于 AtomGit）
